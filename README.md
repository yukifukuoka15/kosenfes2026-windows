# Windows版 LED Button Arcade

Windows 10/11（64bit）で使えるゲーム本体です。Node.jsのインストールは不要です。

## 起動手順

1. このリポジトリ上部の **Code → Download ZIP** で全体をダウンロードします。
2. ダウンロードしたZIPを右クリックして **すべて展開** します。
3. 展開したフォルダ内の **START-WINDOWS.bat** をダブルクリックします。
4. 初回はアプリ一式を展開して起動します。2回目以降も同じバッチで起動できます。

`game.zip.part01` などは容量制限のために分割したデータです。個別に開いたり、名前を変更したりせず、すべて同じフォルダに置いてください。`setup-windows.ps1` と `manifest.json` も必要です。

初回に作られる `LED-Button-Arcade` フォルダ内の `LED Button Arcade.exe` から直接起動することもできます。DLLやresourcesを含むフォルダ全体が必要です。exeだけ移動しないでください。

ESP32とPCは同じLANに接続してください。ファイアウォールの確認ではプライベートネットワークへのアクセスを許可します。

## 確認済みの範囲

Windowsでの起動と同梱音声の読み込み・デコード、画面操作の自動テスト5件、単体・統合テスト354件（既存の4件はスキップ）。実物ESP32、外部ディスプレイ、Switch Proコントローラーでの確認は未実施です。
